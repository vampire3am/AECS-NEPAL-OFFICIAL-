# AECS frontend system

## Direction

Minimal, professional and substantially more expressive across the entire website, as requested after the user rejected the earlier introductory layout. Navy owns the homepage opening and student-platform story; bright surfaces carry planning and reading tasks. Real destination views and AECS team portraits carry imagery. No fabricated admission outcomes, university partnerships or student metrics.

## Typography and hierarchy

Self-hosted Manrope, 400–800. Opening display up to 6rem, with clear line breaks, balanced headings and -0.04em maximum tracking. Public page intros use a stronger display scale. Body copy uses comfortable measures and pretty wrapping. Functional metadata remains at least 11px; working controls generally use 13–16px. Core actions are orange with dark text.

## Colour and composition

Deep navy #112e43; ink #112b40; paper #f0f4f6; orange #f39747; dark orange text #9a430e; white #fcfdfd. Theme uses high-contrast navy regions, destination photography, asymmetrical image composition, open editorial rows and fine dividers. Rounded surfaces are restrained. No decorative gradient text, invented statistics or fake application dashboards.

## Public interactions

Homepage destination tabs change the preview and route link. The planning starter creates a browser draft and continues to the existing study worksheet; test preparation and application tabs lead to actual screens. My AECS has a feature walkthrough with real capability descriptions. The destination directory has a selectable live preview, search, region filters and a persistent comparison tray. Pricing has real package filters. All routes share updated navigation, typography, form styling and footer.

## Working screens

My AECS uses a left sidebar on desktop and scrollable section navigation on phones. Existing authenticated data, application history, document access and staff controls remain server-authorised. Mobile sign-in puts the form before supporting information. Working controls preserve labels, focus, pending, saved, empty and error states.

## Motion and verification

One purposeful destination-image reveal, plus restrained hover feedback. Reduced-motion removes the image reveal and decorative movement. Verify at desktop, intermediate and 390px mobile widths using the installed Impeccable tools and the browser. Deterministic detector findings are evidence to fix, not a design-quality score.
